1. Parasitological & Cellular Profile

  • Apicomplexan Biology (Besnoitia besnoiti / Besnoitiosis): Besnoitia besnoiti is an obligate intracellular coccidian parasite closely related to Toxoplasma gondii and Neospora caninum. In its life cycle, rapidly replicating tachyzoites invade host endothelial and mesenchymal cells during the acute febrile phase, followed by a chronic phase in which slow-dividing bradyzoites encyst within host fibroblasts, histiocytes, and myofibroblasts.
  • Pathology of Dermal & Connective Tissue Cysts: The mature tissue cyst consists of a thick, multilayered capsule (up to 20–30 $\mu\text{m}$ thick) containing a hypertrophied host cell nucleus and thousands of sickle-shaped bradyzoites. In clinical besnoitiosis, millions of microscopic cysts embed in the dermis, fascia, periosteum, and mucosal surfaces, triggering chronic granulomatous sclero-dermatitis, hyperkeratosis (elephant skin), vascular obliteration, and severe local ischemia.
  • Biomechanical Targeting: Because the cyst capsule is composed of dense collagenous fibrils and glycosaminoglycans, conventional antiparasitic medications struggle to achieve therapeutic intracystic concentrations. Acoustic vibration at 887.39 Hz matches the structural resonance of the fibrocystic envelope, creating localized shear stress that compromises cyst wall permeability.

/**
 * Rife887_39Synthesizer - Web Audio API Synthesis Engine for 887.39 Hz
 * Precision Hulda Clark frequency for Besnoitia besnoiti tissue cyst resonance.
 */
class Rife887_39Synthesizer {
  constructor() {
    this.audioCtx = null;
    this.carrier = null;
    this.subOctave = null;
    this.masterGain = null;
    this.isActive = false;
  }

  init() {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    this.audioCtx = new AudioCtx();

    this.masterGain = this.audioCtx.createGain();
    this.masterGain.gain.setValueAtTime(0.0001, this.audioCtx.currentTime);
    this.masterGain.connect(this.audioCtx.destination);
  }

  start(durationMinutes = 35) {
    if (!this.audioCtx) this.init();
    if (this.isActive) return;

    const t = this.audioCtx.currentTime;

    // 887.39 Hz Precision Carrier
    this.carrier = this.audioCtx.createOscillator();
    this.carrier.type = 'sine';
    this.carrier.frequency.setValueAtTime(887.39, t);

    // 443.70 Hz Connective Tissue Sub-Harmonic
    this.subOctave = this.audioCtx.createOscillator();
    this.subOctave.type = 'sine';
    this.subOctave.frequency.setValueAtTime(443.7, t);

    const subGain = this.audioCtx.createGain();
    subGain.gain.setValueAtTime(0.22, t);

    this.carrier.connect(this.masterGain);
    this.subOctave.connect(subGain);
    subGain.connect(this.masterGain);

    // Smooth envelope attack ramp
    this.masterGain.gain.exponentialRampToValueAtTime(0.28, t + 3);

    this.carrier.start(t);
    this.subOctave.start(t);
    this.isActive = true;

    // Scheduled session shutdown
    const stopTime = t + (durationMinutes * 60);
    this.masterGain.gain.setValueAtTime(0.28, stopTime - 3);
    this.masterGain.gain.exponentialRampToValueAtTime(0.0001, stopTime);
    this.carrier.stop(stopTime);
    this.subOctave.stop(stopTime);

    this.carrier.onended = () => {
      this.isActive = false;
    };
  }

  stop() {
    if (!this.isActive || !this.audioCtx) return;
    const t = this.audioCtx.currentTime;
    this.masterGain.gain.linearRampToValueAtTime(0.0001, t + 1);
    setTimeout(() => {
      if (this.carrier) this.carrier.stop();
      if (this.subOctave) this.subOctave.stop();
      this.isActive = false;
    }, 1000);
  }
}
