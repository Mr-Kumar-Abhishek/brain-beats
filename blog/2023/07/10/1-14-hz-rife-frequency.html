1.14 hz - Rife Frequency

10 Jul 2023

The 1.14 Hz Rife Frequency is an infrasonic resonance node derived from the clinical reflexological frameworks of Dr. Paul Nogier and cataloged in the Consolidated Annotated Frequency List (CAFL). It sits in the infrasonic range (below the 20 Hz lower limit of human hearing, so it is felt as vibration or heard only through amplitude modulation of an audible carrier) and is cataloged in the Consolidated Annotated Frequency List (CAFL) for Nogier frequencies.

1. Microbiological & Pathological Profile

  • Nogier Reflexology & Auricular Medicine (Nogier frequencies): In the 1960s, French physician Dr. Paul Nogier pioneered auricular medicine based on the somatotopic mapping of the human body onto the ear (inverted fetus homunculus). Nogier identified a series of harmonic frequencies (Frequencies A through G, fundamentally built upon base frequencies of ~1.14 Hz or 2.28 Hz and scaled by powers of 2: 73 Hz, 146 Hz, 292 Hz, 584 Hz, 1168 Hz, 2336 Hz, 4672 Hz). The 1.14 Hz frequency represents the sub-harmonic foundational base associated with basic cellular vitality, metabolic coordination, and autonomic grounding.
  • Neuroanatomical Substrate & Transcutaneous Vagal Stimulation: The external auricle is uniquely innervated by the auricular branch of the vagus nerve (ABVN, Arnold’s nerve), the auriculotemporal nerve (CN $V_3$), the lesser occipital nerve (C2-C3), and the great auricular nerve. Stimulation of the concha and tragus activates the nucleus tractus solitarii (NTS) in the medulla, delivering systemic parasympathomimetic outflow. Modern bio-electronic medicine utilizes this pathway in FDA-cleared transcutaneous vagus nerve stimulation (tVNS) devices (such as gammaCore, 510(k) K153466 for cluster headache and migraine prevention).
  • Clinical Reality & Biophysical Perspective: While auricular reflexology and low-frequency neuro-stimulation provide compelling models for stress relief, pain modulation, and heart rate variability (HRV) improvement, acoustic frequencies do not directly diagnose or cure underlying organic disease. They operate as psychoacoustic and neuro-sensory entrainment stimuli.

5. Web Audio API Master Synthesizer

/**
 * Rife1_14Synthesizer - Web Audio API Synthesis Engine for 1.14 Hz
 * 1.14 Hz is infrasonic, so it is rendered as amplitude modulation of a 200 Hz carrier.
 */
class Rife1_14Synthesizer {
  constructor() {
    this.audioCtx = null;
    this.carrier = null;
    this.subOctave = null;
    this.masterGain = null;
    this.isActive = false;
  }

  init() {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    this.audioCtx = new AudioCtx();

    this.masterGain = this.audioCtx.createGain();
    this.masterGain.gain.setValueAtTime(0.0001, this.audioCtx.currentTime);
    this.masterGain.connect(this.audioCtx.destination);
  }

  start(durationMinutes = 30) {
    if (!this.audioCtx) this.init();
    if (this.isActive) return;

    const t = this.audioCtx.currentTime;

    // 1.14 Hz is below the hearing range: modulate a 200 Hz carrier at 1.14 Hz
    this.carrier = this.audioCtx.createOscillator();
    this.carrier.type = 'sine';
    this.carrier.frequency.setValueAtTime(200, t);

    // Low-frequency oscillator at 1.14 Hz drives the carrier amplitude
    this.subOctave = this.audioCtx.createOscillator();
    this.subOctave.type = 'sine';
    this.subOctave.frequency.setValueAtTime(1.14, t);

    const depth = this.audioCtx.createGain();
    depth.gain.setValueAtTime(0.5, t);
    const amp = this.audioCtx.createGain();
    amp.gain.setValueAtTime(0.5, t);

    this.subOctave.connect(depth);
    depth.connect(amp.gain);
    this.carrier.connect(amp);
    amp.connect(this.masterGain);

    // Smooth attack ramp
    this.masterGain.gain.exponentialRampToValueAtTime(0.3, t + 3);

    this.carrier.start(t);
    this.subOctave.start(t);
    this.isActive = true;

    // Scheduled session shutdown
    const stopTime = t + (durationMinutes * 60);
    this.masterGain.gain.setValueAtTime(0.3, stopTime - 3);
    this.masterGain.gain.exponentialRampToValueAtTime(0.0001, stopTime);
    this.carrier.stop(stopTime);
    this.subOctave.stop(stopTime);

    this.carrier.onended = () => {
      this.isActive = false;
    };
  }

  stop() {
    if (!this.isActive || !this.audioCtx) return;
    const t = this.audioCtx.currentTime;
    this.masterGain.gain.linearRampToValueAtTime(0.0001, t + 1);
    setTimeout(() => {
      if (this.carrier) this.carrier.stop();
      if (this.subOctave) this.subOctave.stop();
      this.isActive = false;
    }, 1000);
  }
}
