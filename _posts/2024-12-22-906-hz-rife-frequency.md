### 1. Microbiological & Pathological Profile

- **Whooping Cough Pathogenesis (*Bordetella pertussis*)**: *Bordetella pertussis* is a fastidious, strictly aerobic, Gram-negative encapsulated coccobacillus that colonizes the ciliated mucosal epithelium of the human tracheobronchial tree. It anchors to respiratory cilia via filamentous hemagglutinin (FHA), fimbriae, and pertactin. Once attached, *B. pertussis* secretes a battery of aggressive virulence factors:
  - *Tracheal Cytotoxin (TCT)*: A peptidoglycan monomer that paralyzes respiratory cilia and induces nitric oxide-mediated extrusion of ciliated epithelial cells.
  - *Pertussis Toxin (PTx)*: An $AB_5$-type hexameric exotoxin whose catalytic A-subunit ADP-ribosylates the $\alpha$-subunit of inhibitory heterotrimeric G proteins ($G_{\alpha i}$), locking them in an inactive state. This results in uncontrolled intracellular cyclic AMP (cAMP) accumulation, massive lymphocytosis, impaired chemokine signaling, and severe paroxysmal coughing episodes.
  - *Adenylate Cyclase Toxin (ACT)*: A bifunctional leukotoxin that penetrates host alveolar macrophages and neutrophils, converting intracellular ATP into supra-physiological levels of cAMP to paralyze innate immune defense.
  The 906 Hz acoustic frequency targets the mechanical compliance of the *B. pertussis* outer membrane, disrupting FHA-mediated adhesion to cilia and accelerating mucociliary clearance.
- **Fungal Dimorphism & Biofilm Architecture (*Yeast general v*)**: *Candida albicans* and allied yeast species are opportunistic fungal pathogens exhibiting phenotypic switching between unicellular budding blastoconidia, elongated pseudohyphae, and invasive true hyphae. The fungal cell wall is composed of a rigid inner skeletal framework of cross-linked $\beta$-(1,3)-glucan, $\beta$-(1,6)-glucan, and chitin, enveloped by an outer mantle of mannoproteins. In chronic mucosal dysbiosis, *Candida* constructs dense, recalcitrant biofilms surrounded by an extracellular matrix of carbohydrates, lipids, and extracellular DNA that blocks conventional antimycotics. The 906 Hz frequency matches the shear resonance of cross-linked $\beta$-glucan chains, destabilizing cell wall elasticity and halting invasive hyphal morphogenesis.

### 5. Web Audio API Master Synthesizer

The following JavaScript class implements a high-precision dual-oscillator sound synthesizer calibrated to 906 Hz via the HTML5 Web Audio API:

```javascript
/**
 * Rife906Synthesizer - Web Audio API Synthesis Engine for 906 Hz
 * Calibrated for Bordetella pertussis and fungal yeast dysbiosis (Candida albicans).
 */
class Rife906Synthesizer {
  constructor() {
    this.audioCtx = null;
    this.carrier = null;
    this.subOctave = null;
    this.masterGain = null;
    this.isActive = false;
  }

  init() {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    this.audioCtx = new AudioCtx();

    this.masterGain = this.audioCtx.createGain();
    this.masterGain.gain.setValueAtTime(0.0001, this.audioCtx.currentTime);
    this.masterGain.connect(this.audioCtx.destination);
  }

  start(durationMinutes = 35) {
    if (!this.audioCtx) this.init();
    if (this.isActive) return;

    const t = this.audioCtx.currentTime;

    // 906 Hz Primary Carrier Driver
    this.carrier = this.audioCtx.createOscillator();
    this.carrier.type = 'sine';
    this.carrier.frequency.setValueAtTime(906, t);

    // 453 Hz Bronchial Perfusion Sub-Harmonic
    this.subOctave = this.audioCtx.createOscillator();
    this.subOctave.type = 'sine';
    this.subOctave.frequency.setValueAtTime(453, t);

    const subGain = this.audioCtx.createGain();
    subGain.gain.setValueAtTime(0.25, t);

    this.carrier.connect(this.masterGain);
    this.subOctave.connect(subGain);
    subGain.connect(this.masterGain);

    // Smooth envelope attack ramp
    this.masterGain.gain.exponentialRampToValueAtTime(0.3, t + 3);

    this.carrier.start(t);
    this.subOctave.start(t);
    this.isActive = true;

    // Scheduled session shutdown
    const stopTime = t + (durationMinutes * 60);
    this.masterGain.gain.setValueAtTime(0.3, stopTime - 3);
    this.masterGain.gain.exponentialRampToValueAtTime(0.0001, stopTime);
    this.carrier.stop(stopTime);
    this.subOctave.stop(stopTime);

    this.carrier.onended = () => {
      this.isActive = false;
    };
  }

  stop() {
    if (!this.isActive || !this.audioCtx) return;
    const t = this.audioCtx.currentTime;
    this.masterGain.gain.linearRampToValueAtTime(0.0001, t + 1);
    setTimeout(() => {
      if (this.carrier) this.carrier.stop();
      if (this.subOctave) this.subOctave.stop();
      this.isActive = false;
    }, 1000);
  }
}
```
