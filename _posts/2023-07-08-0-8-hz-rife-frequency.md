### 1. Microbiological & Pathological Profile

- **Helicobacter pylori Pathogenesis & Oncoprotein Cascade**: *H. pylori* is an established Group 1 human carcinogen (IARC). Infection induces chronic superficial gastritis that can progress sequentially along Correa's cascade: atrophic gastritis, intestinal metaplasia, dysplasia, and invasive gastric adenocarcinoma. Virulent strains deliver the CagA effector into gastric epithelial cells, driving sustained Erk/MAPK pathway activation and disrupting epithelial polarity complexes (PAR1b/MARK2). Simultaneously, VacA accumulates in mitochondria, inducing cytochrome c release and epithelial apoptosis.
- **Pharmacotherapy & FDA Regulatory Benchmarks**: Clinical guidelines from the American Gastroenterological Association (AGA) and FDA labeling for anti-infective combinations mandate quadruple therapy regimens (e.g., Pylera - bismuth subcitrate potassium, metronidazole, tetracycline; or Voquezna - vonoprazan, amoxicillin, clarithromycin). The FDA cautions that macrolide and fluoroquinolone resistance leads to catastrophic failure of unguided empiric triple regimens. Acoustic frequencies do not possess antimicrobial properties and must not be used in lieu of validated antibiotic eradication therapy.
- **Low-Frequency Mechanical Coupling**: The 0.8 Hz frequency corresponds to a period of $T = 1.25\text{ s}$, which closely aligns with postprandial gastric antral contraction waves and peripheral vasomotion cycles. Gentle low-frequency oscillatory motion is explored in physiological research for its capacity to moderate autonomic tone and promote mucosal capillary perfusion.

### 5. Web Audio API Master Synthesizer

```javascript
/**
 * Rife0_8Synthesizer - Web Audio API Synthesis Engine for 0.8 Hz
 * 0.8 Hz is infrasonic, so it is rendered as amplitude modulation of a 200 Hz carrier.
 */
class Rife0_8Synthesizer {
  constructor() {
    this.audioCtx = null;
    this.carrier = null;
    this.subOctave = null;
    this.masterGain = null;
    this.isActive = false;
  }

  init() {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    this.audioCtx = new AudioCtx();

    this.masterGain = this.audioCtx.createGain();
    this.masterGain.gain.setValueAtTime(0.0001, this.audioCtx.currentTime);
    this.masterGain.connect(this.audioCtx.destination);
  }

  start(durationMinutes = 30) {
    if (!this.audioCtx) this.init();
    if (this.isActive) return;

    const t = this.audioCtx.currentTime;

    // 0.8 Hz is below the hearing range: modulate a 200 Hz carrier at 0.8 Hz
    this.carrier = this.audioCtx.createOscillator();
    this.carrier.type = 'sine';
    this.carrier.frequency.setValueAtTime(200, t);

    // Low-frequency oscillator at 0.8 Hz drives the carrier amplitude
    this.subOctave = this.audioCtx.createOscillator();
    this.subOctave.type = 'sine';
    this.subOctave.frequency.setValueAtTime(0.8, t);

    const depth = this.audioCtx.createGain();
    depth.gain.setValueAtTime(0.5, t);
    const amp = this.audioCtx.createGain();
    amp.gain.setValueAtTime(0.5, t);

    this.subOctave.connect(depth);
    depth.connect(amp.gain);
    this.carrier.connect(amp);
    amp.connect(this.masterGain);

    // Smooth attack ramp
    this.masterGain.gain.exponentialRampToValueAtTime(0.3, t + 3);

    this.carrier.start(t);
    this.subOctave.start(t);
    this.isActive = true;

    // Scheduled session shutdown
    const stopTime = t + (durationMinutes * 60);
    this.masterGain.gain.setValueAtTime(0.3, stopTime - 3);
    this.masterGain.gain.exponentialRampToValueAtTime(0.0001, stopTime);
    this.carrier.stop(stopTime);
    this.subOctave.stop(stopTime);

    this.carrier.onended = () => {
      this.isActive = false;
    };
  }

  stop() {
    if (!this.isActive || !this.audioCtx) return;
    const t = this.audioCtx.currentTime;
    this.masterGain.gain.linearRampToValueAtTime(0.0001, t + 1);
    setTimeout(() => {
      if (this.carrier) this.carrier.stop();
      if (this.subOctave) this.subOctave.stop();
      this.isActive = false;
    }, 1000);
  }
}
```
