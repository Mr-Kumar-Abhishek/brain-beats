The **0.5 Hz Rife Frequency** is a primary delta-range infrasonic node cataloged in the Consolidated Annotated Frequency List (CAFL). It sits in the **infrasonic range** (below the 20 Hz lower limit of human hearing, so it is felt as vibration or heard only through amplitude modulation of an audible carrier) and is cataloged in the Consolidated Annotated Frequency List (CAFL) for **Asthma**, **Backache 2**, **Brachial neuralgia**, **Coughing**, **Hyperthyroid**, and **Muscular pain and injury**.

### 1. Microbiological & Pathological Profile

- **Airway Hyperresponsiveness (*Asthma*, *Coughing*)**: Asthma is a chronic inflammatory disorder of the conducting airways driven by type 2 helper T (Th2) cytokines (IL-4, IL-5, IL-13), leading to eosinophilic infiltration, goblet cell metaplasia, subepithelial fibrosis, and bronchial smooth muscle hyperreactivity. Acute exacerbations produce severe bronchoconstriction and ventilation-perfusion mismatch. The FDA standard of care mandates inhaled short-acting beta-2 agonists (Albuterol, NDA 020983) for acute bronchospasm and inhaled corticosteroids (Fluticasone, Budesonide) for maintenance control. Severe persistent asthma is treated with FDA-approved targeted biologics (Dupilumab, BLA 761055; Mepolizumab, BLA 125526).
- **Neuropathic & Musculoskeletal Pain (*Backache 2*, *Brachial neuralgia*, *Muscular pain*)**: Brachial neuralgia and chronic low back pain stem from mechanical nerve root compression, disc herniation, or myofascial trigger points with elevated local concentrations of substance P, calcitonin gene-related peptide (CGRP), and bradykinin. Non-pharmacologic physical modalities utilize gentle low-frequency oscillatory mobilization to facilitate parasympathetic tone and reduce paraspinal muscle splinting.
- **Endocrine Dynamics (*Hyperthyroid*)**: Hyperthyroidism (primarily Graves' disease or toxic multinodular goiter) causes excessive secretion of triiodothyronine ($T_3$) and thyroxine ($T_4$), precipitating tachycardia, heat intolerance, tremor, and thyrotoxicosis. Clinical treatment requires FDA-approved antithyroid medications (Methimazole, NDA 008688; Propylthiouracil), radioiodine ablation, or thyroidectomy. Vibroacoustic therapy is strictly adjunctive for somatic relaxation and has no inhibitory action on thyroid hormone synthesis.

### 5. Web Audio API Master Synthesizer

```javascript
/**
 * Rife0_5Synthesizer - Web Audio API Synthesis Engine for 0.5 Hz
 * 0.5 Hz is infrasonic, so it is rendered as amplitude modulation of a 200 Hz carrier.
 */
class Rife0_5Synthesizer {
  constructor() {
    this.audioCtx = null;
    this.carrier = null;
    this.subOctave = null;
    this.masterGain = null;
    this.isActive = false;
  }

  init() {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    this.audioCtx = new AudioCtx();

    this.masterGain = this.audioCtx.createGain();
    this.masterGain.gain.setValueAtTime(0.0001, this.audioCtx.currentTime);
    this.masterGain.connect(this.audioCtx.destination);
  }

  start(durationMinutes = 30) {
    if (!this.audioCtx) this.init();
    if (this.isActive) return;

    const t = this.audioCtx.currentTime;

    // 0.5 Hz is below the hearing range: modulate a 200 Hz carrier at 0.5 Hz
    this.carrier = this.audioCtx.createOscillator();
    this.carrier.type = 'sine';
    this.carrier.frequency.setValueAtTime(200, t);

    // Low-frequency oscillator at 0.5 Hz drives the carrier amplitude
    this.subOctave = this.audioCtx.createOscillator();
    this.subOctave.type = 'sine';
    this.subOctave.frequency.setValueAtTime(0.5, t);

    const depth = this.audioCtx.createGain();
    depth.gain.setValueAtTime(0.5, t);
    const amp = this.audioCtx.createGain();
    amp.gain.setValueAtTime(0.5, t);

    this.subOctave.connect(depth);
    depth.connect(amp.gain);
    this.carrier.connect(amp);
    amp.connect(this.masterGain);

    // Smooth attack ramp
    this.masterGain.gain.exponentialRampToValueAtTime(0.3, t + 3);

    this.carrier.start(t);
    this.subOctave.start(t);
    this.isActive = true;

    // Scheduled session shutdown
    const stopTime = t + (durationMinutes * 60);
    this.masterGain.gain.setValueAtTime(0.3, stopTime - 3);
    this.masterGain.gain.exponentialRampToValueAtTime(0.0001, stopTime);
    this.carrier.stop(stopTime);
    this.subOctave.stop(stopTime);

    this.carrier.onended = () => {
      this.isActive = false;
    };
  }

  stop() {
    if (!this.isActive || !this.audioCtx) return;
    const t = this.audioCtx.currentTime;
    this.masterGain.gain.linearRampToValueAtTime(0.0001, t + 1);
    setTimeout(() => {
      if (this.carrier) this.carrier.stop();
      if (this.subOctave) this.subOctave.stop();
      this.isActive = false;
    }, 1000);
  }
}
```
