### 1. Microbiological & Pathological Profile

- **Pathophysiology of HSV-1, Aphthous Stomatitis & Mucosal Breakdown**: Herpes Simplex Virus Type 1 (HSV-1) infects oral mucosal and epidermal tissues, establishing lifelong latent infection in sensory neurons of the trigeminal ganglia. Viral reactivation presents as painful recurrent herpes labialis (cold sores) with intraepithelial vesicles that rupture and form crusts. Recurrent aphthous stomatitis (canker sores) represents a non-viral, cell-mediated ulcerative condition of the non-keratinized oral mucosa driven by localized CD8+ T-cell cytotoxicity, TNF-alpha release, and mucosal micro-ulceration.
- **Therapeutic Regimens & openFDA Clearances**: Recurrent herpes simplex outbreaks are managed with oral Valacyclovir (Valtrex, NDA 020487) or topical/buccal Acyclovir (Zovirax, NDA 018604 / Sitavig, NDA 021478) to inhibit viral DNA synthesis and abbreviate outbreak duration. Recurrent aphthous stomatitis is managed with topical anti-inflammatory corticosteroids such as Triamcinolone acetonide dental paste (Kenalog in Orabase, NDA 012002) to promote mucosal healing and alleviate local pain. Acoustic sound therapy cannot inhibit viral polymerase enzymes or prevent epithelial viral shedding.
- **Audible Mid-Frequency Sound Physics**: At 944 Hz ($T \approx 0.001059\text{ s}$), acoustic waves travel at $\lambda \approx 1.631\text{ m}$ in biological soft tissue and $\lambda \approx 0.363\text{ m}$ in air. The frequency offers a clean, stable auditory pitch for psychoacoustic relaxation, auditory sensory training, and bio-acoustic resonance modeling.

### 5. Web Audio API Master Synthesizer

```javascript
/**
 * Rife944Synthesizer - Web Audio API Synthesis Engine for 944 Hz
 * Synthesizes a clean 944 Hz audible acoustic pure tone with anti-click ramps.
 */
class Rife944Synthesizer {
    constructor(audioCtx = null) {
        this.ctx = audioCtx || new (window.AudioContext || window.webkitAudioContext)();
        this.oscillator = null;
        this.gainNode = null;
        this.isPlaying = false;
    }

    start(volume = 0.5) {
        if (this.isPlaying) return;
        if (this.ctx.state === 'suspended') {
            this.ctx.resume();
        }

        const now = this.ctx.currentTime;
        this.oscillator = this.ctx.createOscillator();
        this.gainNode = this.ctx.createGain();

        this.oscillator.type = 'sine';
        this.oscillator.frequency.setValueAtTime(944, now);

        // Smooth exponential attack ramp to prevent acoustic clicks
        this.gainNode.gain.setValueAtTime(0.001, now);
        this.gainNode.gain.exponentialRampToValueAtTime(Math.max(0.001, volume), now + 0.05);

        this.oscillator.connect(this.gainNode);
        this.gainNode.connect(this.ctx.destination);

        this.oscillator.start(now);
        this.isPlaying = true;
    }

    stop() {
        if (!this.isPlaying) return;
        const now = this.ctx.currentTime;
        this.gainNode.gain.setValueAtTime(this.gainNode.gain.value, now);
        this.gainNode.gain.exponentialRampToValueAtTime(0.0001, now + 0.05);

        setTimeout(() => {
            if (this.oscillator) {
                this.oscillator.stop();
                this.oscillator.disconnect();
            }
            this.isPlaying = false;
        }, 60);
    }
}
```
