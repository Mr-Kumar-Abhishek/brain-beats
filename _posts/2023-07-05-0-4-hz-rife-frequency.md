### 1. Microbiological & Pathological Profile

- **Helicobacter pylori Virulence & Gastric Colonization**: *H. pylori* utilizes helical cell morphology and unipolar flagella to navigate the viscous gastric mucus layer, establishing persistence immediately adjacent to gastric epithelial cells. Upon attachment via outer membrane adhesions (BabA, SabA), the type IV secretion system (T4SS) injects CagA into host cytoplasm, triggering tyrosine phosphorylation by Src-family kinases, activation of SHP-2 phosphatase, and cytoskeletal rearrangement ('hummingbird phenotype'). Concurrently, VacA forms hexameric chloride-selective anion channels in endosomal membranes, causing catastrophic cell vacuolation.
- **Antimicrobial Stewardship & FDA Regulatory Guidance**: The eradication of *H. pylori* is strictly regulated under clinical practice guidelines endorsed by the FDA and the American College of Gastroenterology. Due to surging clarithromycin and levofloxacin resistance rates exceeding 25-30% globally, empiric therapy without antibiotic sensitivity testing requires quadruple regimens incorporating bismuth subsalicylate. FDA product information for Talicia (NDA 213005 - omeprazole, amoxicillin, and rifabutin) underscores that antibiotic stewardship requires completion of full therapeutic courses. Acoustic resonance cannot disrupt bacterial cell walls or substitute for targeted antimicrobial chemotherapy.
- **Infrasonic Mechanical Coupling**: The 0.4 Hz frequency corresponds to an oscillation period of $T = 2.5\text{ s}$. In gastrointestinal physiology, this matches secondary rhythmic contractions of visceral smooth muscle and mesenteric blood flow velocity cycles. Low-frequency rhythmic tactile stimulation is studied for its ability to down-regulate sympathetic visceral hypersensitivity via mechanoreceptor entrainment.

### 5. Web Audio API Master Synthesizer

```javascript
/**
 * Rife0_4Synthesizer - Web Audio API Synthesis Engine for 0.4 Hz
 * 0.4 Hz is infrasonic, so it is rendered as amplitude modulation of a 200 Hz carrier.
 */
class Rife0_4Synthesizer {
  constructor() {
    this.audioCtx = null;
    this.carrier = null;
    this.subOctave = null;
    this.masterGain = null;
    this.isActive = false;
  }

  init() {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    this.audioCtx = new AudioCtx();

    this.masterGain = this.audioCtx.createGain();
    this.masterGain.gain.setValueAtTime(0.0001, this.audioCtx.currentTime);
    this.masterGain.connect(this.audioCtx.destination);
  }

  start(durationMinutes = 30) {
    if (!this.audioCtx) this.init();
    if (this.isActive) return;

    const t = this.audioCtx.currentTime;

    // 0.4 Hz is below the hearing range: modulate a 200 Hz carrier at 0.4 Hz
    this.carrier = this.audioCtx.createOscillator();
    this.carrier.type = 'sine';
    this.carrier.frequency.setValueAtTime(200, t);

    // Low-frequency oscillator at 0.4 Hz drives the carrier amplitude
    this.subOctave = this.audioCtx.createOscillator();
    this.subOctave.type = 'sine';
    this.subOctave.frequency.setValueAtTime(0.4, t);

    const depth = this.audioCtx.createGain();
    depth.gain.setValueAtTime(0.5, t);
    const amp = this.audioCtx.createGain();
    amp.gain.setValueAtTime(0.5, t);

    this.subOctave.connect(depth);
    depth.connect(amp.gain);
    this.carrier.connect(amp);
    amp.connect(this.masterGain);

    // Smooth attack ramp
    this.masterGain.gain.exponentialRampToValueAtTime(0.3, t + 3);

    this.carrier.start(t);
    this.subOctave.start(t);
    this.isActive = true;

    // Scheduled session shutdown
    const stopTime = t + (durationMinutes * 60);
    this.masterGain.gain.setValueAtTime(0.3, stopTime - 3);
    this.masterGain.gain.exponentialRampToValueAtTime(0.0001, stopTime);
    this.carrier.stop(stopTime);
    this.subOctave.stop(stopTime);

    this.carrier.onended = () => {
      this.isActive = false;
    };
  }

  stop() {
    if (!this.isActive || !this.audioCtx) return;
    const t = this.audioCtx.currentTime;
    this.masterGain.gain.linearRampToValueAtTime(0.0001, t + 1);
    setTimeout(() => {
      if (this.carrier) this.carrier.stop();
      if (this.subOctave) this.subOctave.stop();
      this.isActive = false;
    }, 1000);
  }
}
```
