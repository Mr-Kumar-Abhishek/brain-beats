### 1. Microbiological & Pathological Profile

- **Myofascial Pain & Muscle Injury (*Muscular pain*, *Tendomyopathy*)**: Acute and chronic muscular injuries involve micro-tears in sarcomeric Z-discs, localized ischemia, sustained release of intracellular calcium, and persistent contraction of myofibrils forming palpable myofascial trigger points. The standard medical approach employs non-steroidal anti-inflammatory drugs (NSAIDs), FDA-approved centrally acting muscle relaxants (Cyclobenzaprine, NDA 017821; Methocarbamol), physical therapy, and targeted manual release. Low-frequency 1.0 Hz mechanical oscillation promotes tissue relaxation and local capillary washout of metabolic byproducts (lactate, extracellular $K^+$).
- **Toxicological Context (*Pesticide detox*)**: Pesticide toxicity, especially from organophosphates and carbamates, involves irreversible inhibition of acetylcholinesterase (AChE), producing acute cholinergic toxidromes (salivation, lacrimation, urination, bronchospasm, seizures). Medical management is strictly pharmacological, requiring emergency administration of FDA-approved antidotes: atropine sulfate and cholinesterase reactivators such as pralidoxime chloride (2-PAM, Protopam, NDA 014199). Sound frequencies have no biochemical capacity to reactivate phosphorylated enzymes or accelerate toxin elimination.
- **Benign Neoplasms & Catalog Labels (*Tumor benign*, *Complete early crane*)**: Benign tumors (e.g., lipomas, fibromas, leiomyomas) are encapsulated, non-invasive cellular proliferations governed by contact inhibition. 'Complete early crane' represents a historical CAFL catalog label derived from early bio-resonance equipment notes; it possesses no clinical recognition. Suspected masses must be evaluated by licensed physicians using biopsy and diagnostic imaging.

### 5. Web Audio API Master Synthesizer

```javascript
/**
 * Rife1Synthesizer - Web Audio API Synthesis Engine for 1 Hz
 * 1 Hz is infrasonic, so it is rendered as amplitude modulation of a 200 Hz carrier.
 */
class Rife1Synthesizer {
  constructor() {
    this.audioCtx = null;
    this.carrier = null;
    this.subOctave = null;
    this.masterGain = null;
    this.isActive = false;
  }

  init() {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    this.audioCtx = new AudioCtx();

    this.masterGain = this.audioCtx.createGain();
    this.masterGain.gain.setValueAtTime(0.0001, this.audioCtx.currentTime);
    this.masterGain.connect(this.audioCtx.destination);
  }

  start(durationMinutes = 30) {
    if (!this.audioCtx) this.init();
    if (this.isActive) return;

    const t = this.audioCtx.currentTime;

    // 1 Hz is below the hearing range: modulate a 200 Hz carrier at 1 Hz
    this.carrier = this.audioCtx.createOscillator();
    this.carrier.type = 'sine';
    this.carrier.frequency.setValueAtTime(200, t);

    // Low-frequency oscillator at 1 Hz drives the carrier amplitude
    this.subOctave = this.audioCtx.createOscillator();
    this.subOctave.type = 'sine';
    this.subOctave.frequency.setValueAtTime(1.0, t);

    const depth = this.audioCtx.createGain();
    depth.gain.setValueAtTime(0.5, t);
    const amp = this.audioCtx.createGain();
    amp.gain.setValueAtTime(0.5, t);

    this.subOctave.connect(depth);
    depth.connect(amp.gain);
    this.carrier.connect(amp);
    amp.connect(this.masterGain);

    // Smooth attack ramp
    this.masterGain.gain.exponentialRampToValueAtTime(0.3, t + 3);

    this.carrier.start(t);
    this.subOctave.start(t);
    this.isActive = true;

    // Scheduled session shutdown
    const stopTime = t + (durationMinutes * 60);
    this.masterGain.gain.setValueAtTime(0.3, stopTime - 3);
    this.masterGain.gain.exponentialRampToValueAtTime(0.0001, stopTime);
    this.carrier.stop(stopTime);
    this.subOctave.stop(stopTime);

    this.carrier.onended = () => {
      this.isActive = false;
    };
  }

  stop() {
    if (!this.isActive || !this.audioCtx) return;
    const t = this.audioCtx.currentTime;
    this.masterGain.gain.linearRampToValueAtTime(0.0001, t + 1);
    setTimeout(() => {
      if (this.carrier) this.carrier.stop();
      if (this.subOctave) this.subOctave.stop();
      this.isActive = false;
    }, 1000);
  }
}
```
