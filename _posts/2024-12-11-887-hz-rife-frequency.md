### 1. Microbiological & Histopathological Profile

- **Invasive Filamentous Nocardiosis (*Nocardia asteroides*)**: *Nocardia asteroides* is an aerobic, partially acid-fast bacterium possessing branching, beaded filamentous hyphae that fragment into rod-shaped forms. Its cell wall is uniquely enriched with trehalose 6,6'-dimycolate (cord factor) and high molecular-weight mycolic acids, allowing it to survive inside host alveolar macrophages by inhibiting phagosome-lysosome fusion. In clinical infection, it causes suppurative granulomatous pulmonary lesions, subcutaneous abscesses (mycetoma), and metastatic cerebral lesions. The 887 Hz frequency vibrates the long filamentous branching junctions, provoking mechanical fragmentation of delicate hyphal septa.
- **Angioinvasive Mucormycosis (*Mucor racemosus*)**: *Mucor racemosus* belongs to the order Mucorales, characterized by wide (6–15 $\mu\text{m}$), non-septate or sparsely septate ribbon-like hyphae with right-angle branching. The pathogen exhibits intense angiotropism, invading vascular endothelial walls to induce thrombosis, severe tissue ischemia, and dry necrosis. Acoustic resonance at 887 Hz stresses the tensile framework of the chitosan-chitin fungal wall, compromising its structural elasticity.
- **Follicular Epidermoid & Sebaceous Cysts (*Cyst sebaceous TR*)**: Benign intradermal cysts lined with stratified squamous epithelium and filled with laminated, foul-smelling keratinaceous and sebum debris. Chronic inflammation occurs when the cyst wall ruptures, releasing foreign keratin into the dermis. The 887 Hz frequency induces micro-vibrations in viscous sebaceous sebum, facilitating non-inflammatory liquefaction and drainage.

class Rife887Synthesizer {
  constructor() {
    this.audioCtx = null;
    this.carrier = null;
    this.subOctave = null;
    this.masterGain = null;
    this.isActive = false;
  }

  init() {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    this.audioCtx = new AudioCtx();

    this.masterGain = this.audioCtx.createGain();
    this.masterGain.gain.setValueAtTime(0.0001, this.audioCtx.currentTime);
    this.masterGain.connect(this.audioCtx.destination);
  }

  start(durationMinutes = 30) {
    if (!this.audioCtx) this.init();
    if (this.isActive) return;

    const t = this.audioCtx.currentTime;

    // 887 Hz Primary Actinomycetal Driver
    this.carrier = this.audioCtx.createOscillator();
    this.carrier.type = 'sine';
    this.carrier.frequency.setValueAtTime(887, t);

    // 443.5 Hz Lymphatic Decongestive Sub-Harmonic
    this.subOctave = this.audioCtx.createOscillator();
    this.subOctave.type = 'sine';
    this.subOctave.frequency.setValueAtTime(443.5, t);

    const subGain = this.audioCtx.createGain();
    subGain.gain.setValueAtTime(0.22, t);

    this.carrier.connect(this.masterGain);
    this.subOctave.connect(subGain);
    subGain.connect(this.masterGain);

    // Smooth envelope attack ramp
    this.masterGain.gain.exponentialRampToValueAtTime(0.28, t + 3);

    this.carrier.start(t);
    this.subOctave.start(t);
    this.isActive = true;

    // Scheduled session shutdown
    const stopTime = t + (durationMinutes * 60);
    this.masterGain.gain.setValueAtTime(0.28, stopTime - 3);
    this.masterGain.gain.exponentialRampToValueAtTime(0.0001, stopTime);
    this.carrier.stop(stopTime);
    this.subOctave.stop(stopTime);

    this.carrier.onended = () => {
      this.isActive = false;
    };
  }

  stop() {
    if (!this.isActive || !this.audioCtx) return;
    const t = this.audioCtx.currentTime;
    this.masterGain.gain.linearRampToValueAtTime(0.0001, t + 1);
    setTimeout(() => {
      if (this.carrier) this.carrier.stop();
      if (this.subOctave) this.subOctave.stop();
      this.isActive = false;
    }, 1000);
  }
}
