### 1. Microbiological & Pathological Profile

- **Pneumococcal Pathogenesis (*Diplococcus pneumoniae* / *Streptococcus pneumoniae* HC)**: Historically classified as *Diplococcus pneumoniae*, *Streptococcus pneumoniae* is an encapsulated, lancet-shaped Gram-positive facultative anaerobe occurring primarily in pairs or short chains. It is the dominant bacterial pathogen responsible for community-acquired pneumonia, otitis media, acute sinusitis, and invasive bacterial meningitis. Its survival within host tissue hinges upon a thick, hydrated polysaccharide capsule (comprising over 100 distinct serotypes) that physically sterically hinders complement deposition (C3b) and prevents phagocytosis by alveolar macrophages. Additionally, pneumococci synthesize pneumolysin (PLY), a cytotoxic cholesterol-dependent cytolysin that forms large 30 nm oligomeric pores in host alveolar-capillary membranes, inducing alveolar flooding and acute pulmonary necrosis. The 904.74 Hz frequency couples with the viscoelastic oscillatory modes of the polysaccharide capsule, triggering the endogenous autolysin enzyme LytA ($N$-acetylmuramoyl-L-alanine amidase) to initiate bacterial wall collapse.
- **Retroviral Envelope Dynamics (*HIV HC*)**: Human Immunodeficiency Virus (HIV) is an enveloped, positive-sense single-stranded RNA lentivirus characterized by a conical capsid (composed of ~2,000 p24 subunits) housing the viral RNA genome, reverse transcriptase, and integrase. The outer viral membrane is a host-derived lipid bilayer heavily enriched with cholesterol and sphingomyelin, studded with sparse trimeric envelope glycoprotein spikes (each consisting of surface gp120 non-covalently anchored to transmembrane gp41). Infiltration into host CD4+ T helper cells and macrophages requires sequential binding of gp120 to CD4 and chemokine co-receptors (CCR5/CXCR4), prompting a massive conformational rearrangement that exposes the hydrophobic gp41 fusion peptide. class Rife904_74Synthesizer {
  constructor() {
    this.audioCtx = null;
    this.carrier = null;
    this.subOctave = null;
    this.masterGain = null;
    this.isActive = false;
  }

  init() {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    this.audioCtx = new AudioCtx();

    this.masterGain = this.audioCtx.createGain();
    this.masterGain.gain.setValueAtTime(0.0001, this.audioCtx.currentTime);
    this.masterGain.connect(this.audioCtx.destination);
  }

  start(durationMinutes = 35) {
    if (!this.audioCtx) this.init();
    if (this.isActive) return;

    const t = this.audioCtx.currentTime;

    // 904.74 Hz Primary Carrier Driver
    this.carrier = this.audioCtx.createOscillator();
    this.carrier.type = 'sine';
    this.carrier.frequency.setValueAtTime(904.74, t);

    // 452.37 Hz Alveolar Perfusion Sub-Harmonic
    this.subOctave = this.audioCtx.createOscillator();
    this.subOctave.type = 'sine';
    this.subOctave.frequency.setValueAtTime(452.37, t);

    const subGain = this.audioCtx.createGain();
    subGain.gain.setValueAtTime(0.24, t);

    this.carrier.connect(this.masterGain);
    this.subOctave.connect(subGain);
    subGain.connect(this.masterGain);

    // Smooth envelope attack ramp
    this.masterGain.gain.exponentialRampToValueAtTime(0.3, t + 3);

    this.carrier.start(t);
    this.subOctave.start(t);
    this.isActive = true;

    // Scheduled session shutdown
    const stopTime = t + (durationMinutes * 60);
    this.masterGain.gain.setValueAtTime(0.3, stopTime - 3);
    this.masterGain.gain.exponentialRampToValueAtTime(0.0001, stopTime);
    this.carrier.stop(stopTime);
    this.subOctave.stop(stopTime);

    this.carrier.onended = () => {
      this.isActive = false;
    };
  }

  stop() {
    if (!this.isActive || !this.audioCtx) return;
    const t = this.audioCtx.currentTime;
    this.masterGain.gain.linearRampToValueAtTime(0.0001, t + 1);
    setTimeout(() => {
      if (this.carrier) this.carrier.stop();
      if (this.subOctave) this.subOctave.stop();
      this.isActive = false;
    }, 1000);
  }
}
